# VISA Medicina Ocupacional

Site institucional estático, responsivo e com animações progressivas.

## Prévia local

Sirva esta pasta com qualquer servidor HTTP. Não exige instalação nem build. O arquivo principal é index.html.

## Publicação

Preparado para Vercel: preset Other, sem comando de build e saída na raiz. A publicação na Vercel aguarda aprovação.

## Recursos

- Menu móvel acessível e FAQ inicialmente fechado.
- Mapa interativo com 27 UFs e seis pontos de consulta regional.
- Símbolo da marca que se abre e recompõe com a rolagem.
- Contadores, gráficos e entradas com um único controlador por elemento.
- Imagens WebP e fontes locais. Movimento reduzido respeitado.

Os contatos estão em modo de demonstração; os portais apontam para os endereços oficiais.

## Créditos

Identidade, fotos institucionais e marcas de clientes: materiais fornecidos pela VISA.
Fotografias ilustrativas: Unsplash (photo-1576091160399-112ba8d25d1d).
Mapa: Code for America / Click That Hood, brazil-states.geojson.
